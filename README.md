# 💸 Desconto Inteligente

Um sistema desenvolvido com **HTML, CSS e JavaScript** que verifica se um cliente tem direito a um desconto com base em duas condições: ser cliente VIP ou realizar uma compra acima de R$ 190,00.

## 📌 Sobre o projeto

O **Desconto Inteligente** foi criado como um projeto de prática para aplicar conceitos fundamentais de lógica de programação e desenvolvimento web.

A aplicação analisa as informações do cliente e o valor da compra para informar se ele possui direito ao desconto.

## ⚙️ Funcionalidades

- Verificação de cliente VIP.
- Análise do valor da compra.
- Aplicação de condições lógicas.
- Exibição de mensagens na tela.
- Interface desenvolvida com HTML e CSS.

## 🧠 Conceitos praticados

- Variáveis em JavaScript.
- Operadores de comparação.
- Operadores lógicos (`||`).
- Estruturas condicionais (`if` e `else`).
- Eventos e interação com o usuário.
- Manipulação do DOM.
- Conversão de valores com `Number()`.

## 📋 Regras do sistema

O cliente terá direito ao desconto se atender a pelo menos uma das seguintes condições:

- Ser cliente VIP.
- Realizar uma compra superior a R$ 190,00.

Se nenhuma das condições for atendida, o sistema informará que o cliente não possui direito ao desconto.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Informe o valor da compra e a condição de cliente VIP.
5. Verifique o resultado apresentado na tela.

## 🎯 Objetivo

Praticar lógica de programação e compreender como utilizar JavaScript para criar aplicações web interativas, trabalhando com condições, operadores e manipulação do DOM.
